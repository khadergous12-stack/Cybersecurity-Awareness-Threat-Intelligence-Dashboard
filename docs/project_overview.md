# Cybersecurity Awareness & Threat Intelligence Dashboard

## Project Overview

The Cybersecurity Awareness & Threat Intelligence Dashboard is a defensive cybersecurity platform designed to analyze synthetic threat intelligence data, validate Indicators of Compromise (IOCs), calculate risk, correlate threats with organizational assets, generate security alerts, and provide cybersecurity awareness content.

## Objectives

- Analyze threat intelligence records using a structured dataset.
- Validate IP addresses, domains, URLs, email addresses and hashes.
- Calculate and display threat risk and confidence.
- Correlate indicators with organizational assets.
- Generate security alerts from correlated threats.
- Identify and prioritize vulnerability exposure.
- Provide cybersecurity awareness modules and an interactive quiz.

## Main Modules

1. Threat Intelligence
2. IOC Validation and Search
3. Risk Analysis
4. Threat Enrichment
5. Asset Correlation
6. Alert Management
7. Vulnerability Management
8. Security Awareness
9. Security Awareness Quiz
